**Covid19-data-analysis**

COVID-19 portfolio project analyzing global cases, deaths, infection rates, and vaccination trends using MySQL and Excel.

The dataset used for this analysis is from: https://github.com/ChristineCYin/Covid-19-Data-Exploration

Hannah Ritchie, Esteban Ortiz-Ospina, Diana Beltekian, Edouard Mathieu, Joe Hasell, Bobbie Macdonald, Charlie Giattino, Cameron Appel, Lucas Rodés-Guirao, and Max Roser (2020). Published online at OurWorldInData.org. 

Downloaded on 6/10/2026

**Project Overview**

Data Import and Cleaning: Imported the Covid Deaths and Vaccinations tables with the correct data type for each column.
Data Processing: Processed data using aggregate functions, joins, and CTEs, and created views in SQL.
Data Visualization: Created interactive dashboards in Tableau to visualize the analysis results.
